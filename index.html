O Safari (e o Chrome do iPhone) não suportam Bluetooth em páginas web. Para usar este controle:

  1. Instale o app gratuito Bluefy – Web BLE Browser.
  2. Abra este mesmo endereço (https) dentro do Bluefy.
  3. Toque em "Conectar ao ESP32".
O Bluetooth só funciona se a página for aberta por https:// (ex.: GitHub Pages), não como arquivo local.
